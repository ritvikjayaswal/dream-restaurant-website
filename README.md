# Dream Restaurant

This repository contains a small static demo website for "Dream Restaurant" — suitable for quick deployment to Vercel.

How to deploy on Vercel

1. Go to https://vercel.com and sign in.
2. Import the GitHub repository `ritvikjayaswal/dream-restaurant-website`.
3. For a static site, Vercel will detect and deploy automatically; no build command is required.

If you want automatic preview URLs on every branch or GitHub integration, enable the Vercel Git integration during import.
